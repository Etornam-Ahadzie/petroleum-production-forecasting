
# Petroleum Production Forecasting Using Machine Learning

## Project Overview

This project investigates the application of machine learning and statistical models to petroleum production forecasting.

Three modelling approaches are considered:

- Extreme Gradient Boosting (XGBoost)
- Random Forest (RF)
- Autoregressive Integrated Moving Average (ARIMA)

The objective is to evaluate their predictive performance and identify the most suitable model for forecasting oil and gas production.

## Methodology

1. Data preparation and preprocessing.
2. Exploratory data analysis.
3. Feature and target normalisation.
4. Chronological training and testing split.
5. Model development and hyperparameter optimisation.
6. Model performance evaluation.

## Evaluation Metrics

- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
